# 文件与文档治理模块

## 触发范围

当任务创建、迁移、归档、删除或大幅重写项目文件、文档、模板或生成产物时启用。普通的小型源代码修改无需单独加载本模块。

## 先发现项目事实

- 查找项目现有目录结构、命名规范、文档入口、生成流程、归档方式和前置 metadata 约定。
- 区分规范源与生成物；生成物应通过项目已有流程更新，不直接手改。
- 确认目标文件的所有者、引用点、保留要求和可恢复方式；删除或迁移前先确认精确范围。

## 最小质量门槛

- 遵循既有结构和项目约定：正式文档、草稿、一次性临时产物与归档内容按项目已有规则放置；项目未定义时不强加固定目录树。
- 名称表达内容和状态，避免 `final`、`final_v2`、`new`、`temp` 等低信息量命名。
- 仅在项目已有规范或目标文件需要时使用 frontmatter；不为统一格式而给所有 Markdown 增加元数据。
- 改动后检查引用、导航、生成入口和受影响验证；无法安全确定归档或删除后果时停下并报告。
