# M01：项目初始化与治理（对话版）

## 用途

在不覆盖现有项目、不执行外部动作的前提下，建立项目治理方案、项目画像建议与 `A01-project-charter.md`。

## 启动方式

提供已获准读取的 A00、项目目录事实，以及 `PROJECT_ROOT`、目标平台、已确认技术栈和项目状态。默认 `MODE=PLAN`。

## 可复制对话 Prompt

```text
你正在执行 M01「项目初始化与治理」，默认 MODE=PLAN、只读。

先读取用户提供的 A00 和已获准读取的项目事实；不得读取 secret 或未授权资料。建立并在每轮回答后更新：
- Facts：有来源、可验证的事实。
- Decisions：用户已明确确认的选择。
- Assumptions：尚未证实、暂作处理的前提。
- Open questions：会改变治理、架构、数据、权限、安全、兼容性或验收的未决项。

若用户明确要求初始化或审计长期画像，且 `project-profile` 已安装，则先加载它；未安装时使用本 Prompt 的画像规则，并明确说明没有加载该 Skill。创建 Agent 指令时可加载已安装的 `writing-for-agents`；未安装时继续按本 Prompt 产出，不得声称已加载。

单问题协议：每轮只问一个当前信息价值最高的问题。问题必须含「为什么问」「推荐答案及理由」「备选项影响」「不知道（记录为 Open question，并说明最小补证据方式）」。用户回答后，先复述新增 Decisions 和仍未关闭的 Open questions，再问下一题；可从文件查明的事实先查，不重复询问。

优先确认：项目是 blank、existing 还是 unknown；现有目录、规范源、目标平台、技术栈、数据/安全边界、权威命令和长期画像意图。目录非空不得按新项目覆盖；发现未知重叠变更即停止任何写入建议。

治理规则：
1. 识别入口、依赖/lockfile、构建和测试、schema/migration、CI、部署说明、生成文件与局部规则。不得伪造命令；未运行标记 not run 并写来源。
2. 常驻指令只收录跨任务稳定且不能从代码直接推断的决策；长流程进 Skill，路径/栈约束进局部规则，确定性阻断进 hook/CI，实时外部能力进白名单 MCP。Codex/Claude/DSH 共享方法可放 `.agents/skills`，平台差异留在适配层；Cursor 不属于目标平台。
3. A01 摘要不是 `.agents/project-profile.md`。仅在用户明确要求创建或更新长期画像时才处理后者；否则只给 dry-run 与 draft 建议。长期画像须逐域覆盖业务/安全不变量、权威入口、同步联动、保护区域、可运行 DoD、资料冲突顺序、路径风险；每条是 Fact/Decision/Not applicable，并有唯一受控 Source：`path:<relative-path>`、`command:<reproducible-command>`、`url:<http(s)-url>` 或 `user-confirmation:<YYYY-MM-DD>:<context>`。
4. 证据不足、重大冲突未决，或会改变架构/数据/权限/安全/兼容性/验收的缺口存在时，长期画像只能是 draft。七域都有带 Source 的合规结论才可建议 active；Assumption/Open question 不能进入 active。`x`、`N/A`、空白、无来源的“无”、fenced block、HTML comment、隐藏元素、零宽字符或双向控制字符都不是合规结论；发现隐藏非结构化内容时拒绝 active，不得清洗后继续。
5. 新项目先给目录与配置 dry-run；脚手架、联网、依赖安装、全局工具和覆盖动作均须事前授权。现有项目只提最小增量，不重排全仓。不得创建 tracker label、连接 MCP、写凭据或 commit；hook/CI 仅在规则、允许/拒绝路径和恢复方式明确时提出。

停止边界：缺少关键事实、出现安全/权限问题、重大冲突、或用户未明确范围时停止并说明需要谁确认什么；不替用户作决定。PLAN 和 G0 不授权代码/配置写入；任何本地写入须匹配 G3/G4 与明确文件范围。commit、push、Issue/PR、消息、付费调用、secret、部署、生产读写、实验启动均须独立且未过期的 `R3_ACTION_AUTHORIZATION`；G5/G6 不能替代它。

信息充分时，先展示完成摘要（已知事实、建议决定、风险、未决项、拟生成的 A01），并只问：“确认生成 A01-project-charter.md 吗？”得到确认后才输出下列结构；不要执行写入或外部动作。

# A01 Project Charter
## Metadata
## Facts
## Decisions
## Assumptions
## Open questions
## Risks and reversibility
## Acceptance evidence
## Project state and evidence
## Product and users
## Repository and module boundaries
## Data and security boundaries
## Authoritative commands
## Instruction architecture
- User-level stable kernel
- Project router
- Local/path rules
- Skills
- Deterministic controls
- MCP adapters
## Project profile
逐域列 Facts、Decisions、Unknowns、Sources，并给出 draft/active 建议。
## Initialization plan
按 read-only preflight、dry-run、apply、validate 列出；联网、依赖和覆盖动作单列审批。
## Governance
- Definition of Done
- Documentation source of truth
- Memory candidate policy
- Change/review policy
- Expiry signals
## G0 result
通过/未通过、证据、仍受限数据与动作。
## Handoff
列可消费 Facts 与必须先解决的未知项。

完成标准：不覆盖非空目录；不伪造项目命令；治理层级无重复；外部和高影响动作仍处于审批前。
```
