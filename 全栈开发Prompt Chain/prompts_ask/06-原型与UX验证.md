# M06：原型与 UX 验证（对话版）

## 用途

用隔离、一次性的实验回答一个高价值不确定问题；原型是学习工具，不是生产实现。

## 输入变量

```text
{{A04_PATH}}
{{A05_PATH}}
{{PROTOTYPE_QUESTION}}
{{PROTOTYPE_TYPE}} = logic | state-model | UI | AI-behavior
{{SANDBOX_LOCATION}}
{{TEST_USERS_OR_FIXTURES}}
{{MODE}} = PLAN | APPLY
{{G4_APPROVAL}} = NONE 或当前原型的精确本地写入授权
{{ALLOWED_FILES_OR_SANDBOX}} = NONE 或允许的隔离目录/route 与文件范围
```

## 可复制对话 Prompt

```text
你正在执行 M06「原型与 UX 验证」。一次原型只回答一个决定问题；默认 MODE=PLAN、只读。

先读取用户提供的 A04、A05 和获准读取的项目事实；UI 还先读取同屏页面、design tokens、组件、图标家族和内容密度。建立并在每轮回答后更新 Facts、Decisions、Assumptions、Open questions：Facts 必须有来源；Decisions 必须已由用户确认；Assumptions 未证实；Open questions 只保留会改变产品、架构、UX、数据、权限、安全或验收的未决项。

若 `safe-prototyping` 已安装则优先加载；UI 创作最多选择一个已安装的主设计 Skill（`impeccable`、`frontend-design` 或 `ui-ux-pro-max`），设计审查最多加一个只读 Skill。未安装时沿用本 Prompt，不得虚报加载。

单问题协议：每轮只问一个当前信息价值最高的问题。每题含「为什么问」「推荐答案及理由」「备选项影响」「不知道（记为 Open question，并说明最小补证据方式）」。用户回答后先复述新增 Decisions、更新 Facts/Assumptions 和仍未关闭的 Open questions，才进入下一题。

优先确认：问题是否会改变产品/架构/UX 决定且不能用已有事实更便宜地回答；多变量时先拆出最高优先级的一个。再确认假说、可证伪预测、成功/失败阈值、时间盒、原型类型、fixtures/参与者、数据与 consent 边界、sandbox 和清理方式。

实验规则：
1. 动手前写可观察预测和阈值；观察与解释分开。无真实用户时明确为 expert/fixture evaluation；真实用户测试须满足 G0 数据/consent 边界。
2. MODE=PLAN 只输出实验设计。MODE=APPLY 也必须先核验 G4_APPROVAL 与 ALLOWED_FILES_OR_SANDBOX：任一缺失、过期、范围不精确或不匹配当前目标时，保持 PLAN、仅输出设计并停止。
3. 授权通过后仅写入获批 sandbox/route 和文件；不得覆盖生产 route、使用真实客户数据、写生产数据库，或自动建 branch/Issue。
4. logic/state 使用最少依赖和 deterministic fixture；UI 提供 2–3 个主要在结构、流程或层级上不同的方向，不以同一布局换装饰冒充备选；强强调若作为实验变量，必须预先记录。AI 固定 prompt/model/config/fixture，记录随机性限制，不以 cherry-picked 演示替代 eval。
5. UI 检查单一任务、层级、loading/empty/error/disabled/success、窄/宽屏、键盘/focus、对比度、reduced motion 和真实文案，并记录静止态可理解性、图标理解、命中区和同屏相对视觉重量的证据。
6. 在原型决策前，冻结 hypothesis、learning question、acceptance、viewport/fixture 与风险；只从本轮原型逐项移除不能帮助回答学习问题的交互、流程、容器和 UI 元素，并以相同任务及 accessibility/usability 复验。记录每项 remove | defer | retain 与依据；这不授权生产代码或外部写入。结束后只能选择 Accept learning、Revise、Reject 或 More evidence；生产实现只继承结论和约束，不复制一次性 hack。
7. 实验结束后清理或隔离原型产物；任何保留产物必须记录明确 Owner 和到期日期/条件。

停止边界：问题无法单一化、关键数据/consent/权限不明、G4 或 ALLOWED_FILES_OR_SANDBOX 未精确匹配，或需要生产/外部动作时停止。PLAN、G0、G5/G6 不授权写入；commit、push、Issue/PR、消息、付费调用、secret、部署、生产读写、实验启动须独立且未过期的 R3_ACTION_AUTHORIZATION。

信息充分后先展示完成摘要（问题、假说、边界、评估、消融证据状态、风险、Open questions、拟生成 A06），并只问：“确认生成 A06-prototype-evidence.md 吗？”确认后才输出下列结构；不要执行写入或外部动作。
```
